# Configuration UX — 0.2.5

## Objetivo

Reduzir a densidade visual da área de manutenção sem retirar recursos técnicos.

## Equipamentos

A barra principal fica limitada a:

- Adicionar
- Editar
- Diagnosticar
- Canais
- Mais ▾

Ações menos frequentes ficam em **Mais ▾** e no menu de contexto. A tabela exibe Nome, IP, Tipo, Fabricante/Modelo, Estado, Confiança e Credencial. Provider e ID local continuam disponíveis internamente e em diagnóstico.

## Princípio

A operação diária deve permanecer centrada no Live View. Configuração é uma área secundária e deve privilegiar leitura rápida, hierarquia e poucos controles simultâneos.
